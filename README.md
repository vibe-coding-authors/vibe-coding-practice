# 바이브 코딩 교재 실습 자료

바이브 코딩 교재에서 사용하는 실습 자료와 프롬프트를 모아 둔 저장소입니다.

## 내려받는 방법

1. 이 페이지 위쪽의 **Code** 버튼을 누르고 **Download ZIP**을 선택해 전체 자료를 내려받습니다.
2. 장별 자료만 필요하면 아래 표에서 해당 압축 파일을 눌러 **Download raw file**(다운로드 아이콘)로 내려받습니다.
3. 각 장의 [실습 시작]에 적힌 대로 `C:\vibe\chapterNN` 폴더에 압축을 풀어 사용합니다.

## 장별 실습 자료

| 장 | 제목 | 파일 | 주요 내용 |
|---|---|---|---|
| 제2장 | 바이브 코딩 프로세스와 프롬프트 | `chapter02.zip` | 사례자료, 실습지, 예시답안(docx) |
| 제4장 | 파일 관리 자동화 프로그램 제작 | `chapter04.zip` | PRD 예시, 분류 실습용 더미 파일(Before / Expected_After) |
| 제5장 | 엑셀 데이터 분석 및 시각화 프로그램 제작 | `chapter05.zip` | PRD, 지점별 주간 판매 엑셀 |
| 제7장 | 재고 목록 관리 자동화 프로그램 제작 | `chapter07.zip` | 전산비품 구매대장, 지급대장(xlsx) |
| 제9장 | Git과 버전 관리·웹 배포 | `chapter09.zip` | 디지털 명함 예제(start / after-restore / after-update) |
| 제10장 | 외부 API를 활용한 업무 자동화 | `chapter10.zip` | PRD, 해외 영수증 사진 |
| 제11장 | 업무 관리 웹 프로그램 제작 | `chapter11.zip` | 단계별 소스(source), 완성본(task-manager) |
| 제12장 | 내 웹 프로그램을 스마트폰 앱(PWA)으로 확장하기 | `chapter12.zip` | PRD, 시작 소스(source) |

실습 자료가 없는 장(제1·3·6·8장)은 본문의 안내에 따라 진행합니다.

## 프롬프트

`프롬프트.xlsx`에 교재의 모든 프롬프트를 장별·번호별로 정리했습니다. 본문에서 가운데를 줄인 프롬프트도 같은 번호로 전체 내용을 확인할 수 있습니다.

## 주의

- 실습 자료에 들어 있는 이름, 연락처, 영수증 등은 모두 실습용 예시입니다.
- API 키, 비밀번호 같은 개인 정보는 이 저장소나 실습 파일에 올리지 않습니다.
